### 1. `job-writer-url` — All-in-One 채용 분석 & 자소서 완성 마스터 엔진
단 1개의 공고 URL(또는 텍스트)과 자소서 문항을 입력받아, 과거 합격 DNA 벤치마킹부터 3-in-1 심층 분석, 완성형 자소서 집필, ATS 최적화, 압박 면접 질문 추출, Notion 지원 관리 DB 자동 동기화(Write-back)까지 원스톱으로 처리합니다.

* **동작 방식 (2-Stage Interactive Mode)**:
  1. **STAGE 0 (합격 레퍼런스 벤치마킹)**: Notion '기업 채용공고 목록 DB'에서 과거 서류 합격 데이터를 탐색(1순위: 동일기업, 2순위: 유사직무, 3순위: 최근합격)하여 성공 DNA 추출.
  2. **STAGE 1 (3-in-1 분석 & 전략 설계도)**: 기업 360도 분석, 직무 밸류체인 분석, Notion 실경험 1:1 매핑, 문항별 자소서 작성 전략 Blueprint 출력 후 사용자 승인 대기.
  3. **STAGE 2 (완성본 집필 & 검증 & 동기화)**: 비즈니스 6대 원칙에 입각한 자소서 완성본(85~95% 글자수 충족), ATS Top 10 키워드 매칭률 매트릭스, 압박 면접 질문 3~5선 및 방어 논리, Notion DB 자동 역동기화.

* **사용 예시**:
```markdown
/job-writer-url https://recruit.hyundai.com/job/12345
[문항 1] 현대자동차 해당 직무에 지원하게 된 동기와 본인이 적합하다고 판단하는 이유를 서술해 주십시오. (1,000자)
[문항 2] 지원 분야와 관련하여 본인이 보유한 직무 전문성(Hard/Soft Skill)과 이를 확보하기 위한 노력 과정을 구체적으로 기술해 주십시오. (1,000자)
```

### 2. `fitting` — 다중 직무 적합도 매칭 & 우선순위 분석 엔진
PDF 공고문, 채용 URL, 또는 텍스트 내의 **여러 모집 직무(Multi-Role)**를 파싱하여 지원자의 Notion 경험 DB와 대조하고, 정량 점수(100점 만점)와 근거 기반의 **직무 우선순위 랭킹(Priority Ranking)**을 도출합니다.

* **핵심 기능**:
  - 다중 모집 직무(JD) 자동 추출 및 R&R/필수/우대 요건 파싱
  - Notion '자기소개서 경험 관리' DB 연동 (프로젝트, 교육, 스택, 공학 표준 실시간 인출)
  - 4대 다각 평가지표(기술 스택 35점 + 실무 프로젝트 35점 + 도메인 이해도 15점 + 정량 스펙 15점) 100점 환산
  - 직무별 적합도 랭킹(1~3순위), Why #1 선정 근거, 결측 역량(Gap) 방어 논리, 타겟 키워드 제공

* **사용 예시**:
```markdown
/fitting https://recruit.skhynix.com/careers/notice/12345
```

### 3. `q-a` — 자기소개서 문항별 글자수 배분 & 구조 설계 엔진 🌟 NEW
자기소개서 문항과 글자수(500자~2,000자)를 입력받아, 서류 탈락 방지 필독 체크리스트, 문항 유형별 핵심 접근법, 두괄식 Start 후킹 템플릿, 초정밀 글자수 배분 구조(소제목/Start/Middle/End), 소재 배치 원칙(Sync 우선)을 추천합니다.

* **핵심 기능**:
  - **서류 탈락 방지 Checklist & 킬러 문장 대비표**: 회사 찬양, 진부한 포부, 일반 키워드 단독 사용 탈피
  - **문항별 초정밀 글자수 배분 (Blueprint)**: Start(15~20%), Middle(60~70%), 마무리(15~20%) 정량 구간 제시
  - **스펙 티어보다 직무 싱크 (Sync > Tier)**: JD 키워드와 일치하는 실무 연관 소재 전면 배치 원칙
  - **두괄식 후킹 Start 문장 템플릿**: 평가자의 3초 스크리닝을 사로잡는 첫 문장 패턴 제공

* **사용 예시**:
```markdown
/q-a
[1번] 지원동기와 입사 후 회사에서 이루고 싶은 꿈 (1,000자)
[2번] 지원 직무를 위해 필요한 역량과 이를 갖추기 위한 노력 과정 (1,000자)
[3번] 다른 지원자 대비 차별화된 강점과 보완할 약점 (800자)
```

### 4. `job-posting-analyzer-url` — 다중 직무 채용공고 URL 전수 심층 분석 엔진
채용 공고 URL(또는 공고 페이지 전문)을 입력받아, 해당 페이지에 등록된 **모든 모집 직무(Multi-Role)**를 자동 추출하고, 각 직무별로 `job-posting-analyzer` 수준의 고밀도 심층 비즈니스 분석을 전수 실행합니다. 직무 수가 많을 경우 **2~3회에 걸쳐 자동으로 분할(Smart Batching)**하여 품질 저하 없이 상세 리포트를 제공합니다.

* **핵심 기능**:
  - URL 내 모든 모집 직무(JD) 자동 추출 및 R&R/필수/우대 요건 파싱
  - 직무 수에 따른 스마트 분할 브리핑 (1~2개: 1회 완료, 3~4개: 2회 분할, 5개 이상: 3회 분할)
  - 직무별 4대 핵심 분석 (비즈니스 언어 전환 표, 밸류체인 내 역할, 실무 페인포인트 Top 3 시나리오, 추천 레퍼런스)
  - 전 직무 밸류체인 연계 & 협업 시너지 맵 및 성향별 지원자 직무 선택 퀵 가이드

* **사용 예시**:
```markdown
/job-posting-analyzer-url https://recruit.hyundaimobis.com/job/notice/12345
```

### 5. `job-url` — 올인원 채용 분석 리포트 생성기
공고 URL(또는 텍스트)을 입력받아 `company-deep-analyzer`, `job-posting-analyzer`, `job-application-strategist`의 분석 역량과 Notion 경험 DB를 단일 리포트로 통합 출력하는 분석 전용 마스터 스킬입니다.

* **사용 예시**:
```markdown
/job-url https://careers.koreaaerospace.com/job/67890
```

### 6. `company-deep-analyzer` — 기업 360도 심층 분석
특정 대상 기업의 정체성, 사업 포트폴리오, 3개년 재무 추이, 최신 이슈를 다각도로 리서치하여 자소서 지원동기/포부 및 임원 면접에 직결되는 인사이트를 도출합니다.

* **사용 예시**:
```markdown
현대모비스의 최근 3개년 재무와 신사업 전략을 바탕으로 company-deep-analyzer 분석 보고서를 작성해줘.
```

### 7. `job-posting-analyzer` — 직무 기술서(JD) 심층 분석
채용 공고의 문구를 현업 관점의 실무 비즈니스 언어로 재정의하고, 기업 전체 밸류체인 속에서의 직무 역할과 실무 대표 이슈를 분석합니다.

* **사용 예시**:
```markdown
이 채용공고의 필수/우대 조건을 job-posting-analyzer 기준으로 분석해줘:
[채용공고 담당업무 및 자격요건 텍스트]
```

---

### 8. `job-application-strategist` — 지원자 경험 매핑 및 서류/면접 전략
채용 공고와 자소서 문항을 분석하여 채용 담당자의 숨겨진 니즈(Hidden Needs)를 역추적하고, 지원자의 Notion 경험 DB와 1:1로 매핑하여 합격 전략을 수립합니다.

* **사용 예시**:
```markdown
현대오토에버 차량SW 개발 직무 공고와 내 Notion 경험 DB를 기반으로 job-application-strategist 합격 전략을 짜줘.
```

### 9. `writer-job` — 10년 차 컨설턴트/임원 평가 기준 전문 자소서 작성 및 첨삭
대기업 인사임원 평가 기준과 비즈니스 문서 6대 원칙(`내·형·표·구·간·명`)을 기반으로, 지원자의 실제 경험 데이터를 고밀도 합격 자기소개서로 집필하거나 첨삭합니다.

* **사용 예시**:
```markdown
writer-job 프레임워크를 적용해서 내 [H-Mobility Class 자율주행 Track] 경험을 활용해 현대자동차 지원동기 1,000자를 작성해줘.
```

### 10. `cover-letter-evaluator` — 자기소개서 객관 평가 및 100점 채점기
자기소개서 초안을 수정하지 않고, 대기업 인사임원 및 15년차 컨설턴트의 시각에서 6대 지표(100점 만점)로 객관 평가하고 구체적인 개선 방향을 제공합니다.

* **사용 예시**:
```markdown
공고 URL과 내가 쓴 현대모비스 1번 문항 자소서 초안을 줄게. cover-letter-evaluator로 객관적으로 평가해줘:
[공고 URL]
[문항 및 글자수]
[작성한 초안]
```

### 2. 일상 동기화 방법

#### 방법 A: 원클릭 동기화 스크립트 사용 (`sync.ps1`)
```powershell
cd $HOME\.gemini\config\skills

# [가져오기] 다른 기기에서 수정한 최신 스킬 당겨오기
.\sync.ps1 pull

# [올리기] 현재 기기에서 수정한 스킬 GitHub에 푸시하기
.\sync.ps1 push "q-a 신규 스킬 추가 및 README 업데이트"

# [상태 확인]
.\sync.ps1 status
```

#### 방법 B: 일반 Git 명령어 사용
```powershell
cd $HOME\.gemini\config\skills
git pull origin main
git add .
git commit -m "q-a 신규 스킬 추가 및 README 업데이트"
git push origin main
```
