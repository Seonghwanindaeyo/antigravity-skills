# 올인원 채용 분석 및 자기소개서 완성 엔진 (job-writer-url)

이 스킬은 **단 1개의 채용 공고 URL(또는 공고 텍스트)과 자기소개서 문항 리스트**를 입력받아, **2단계 인터랙티브 모드(Interactive Mode)**를 통해 LLM 토큰 병목 및 품질 저하를 원천 방지하면서 3-in-1 심층 분석, Notion 실경험 매핑, 완성형 자소서 집필("가장 취약한 점" R-C-S-V 특화 프로토콜 포함), ATS 키워드 검증, 면접 꼬리 질문 추출, Notion 지원 이력 역동기화(Write-back)까지 완벽하게 수행하는 마스터 엔진입니다.

> ★ **핵심 원칙 — 리서치 → 집필 직결 (Research-to-Writing Pipeline)**
> STEP 1에서 웹 서칭한 기업 정보(재무, 신사업, 최신 뉴스, CEO 메시지, 인재상, 정책 이슈)는 **분석 리포트에서 끝나지 않고**, 번호가 매겨진 **'리서치 팩트 시트(F1, F2 …)'**로 정리되어 **사용자가 제시한 모든 자소서 문항의 집필 재료로 반드시 활용**됩니다.

## 2. STAGE 1 세부 수행 지침 (분석 & 전략 수립)

### 1) 데이터 수집 및 웹 리서치
* `read_url_content`로 채용 공고 전문을 수집하고 기업명, 지원 직무, 필수/우대 요건을 추출합니다. (URL 접근 불가 시 입력된 텍스트 직접 활용)
* `search_web`으로 아래 **6대 리서치 항목**을 조사합니다. 사용자가 제시한 **자소서 문항의 성격을 먼저 확인한 뒤, 문항 작성에 필요한 정보를 우선순위로 서칭**합니다.
  1. **재무·사업 구조**: 최근 3개년 매출/영업이익 추이, 사업부별 매출 비중, R&D 투자
  2. **신사업·중장기 전략**: 신규 투자, 신공장/신제품, 기술 로드맵, 중장기 목표 수치
  3. **최근 1년 핵심 뉴스 5선**: 수주, 양산, 리콜·품질 이슈, M&A, 파트너십 등
  4. **CEO 신년사 / 경영진 메시지**: 올해 경영 화두와 키워드
  5. **비전·인재상·핵심가치**: 공식 채용 페이지 기준 원문 표현
  6. **산업·정책 이슈**: 규제, 정부 정책(산자부 등), 경쟁사 동향, 시장 리스크/기회

### 2) ★ 리서치 팩트 시트(Research Fact Sheet) 작성 — 필수
웹 리서치 결과를 자소서에 바로 넣을 수 있는 **번호가 매겨진 팩트 단위**로 정리합니다.

| 규칙 | 내용 |
| :--- | :--- |
| **번호화** | 모든 팩트에 `F1, F2, …` ID를 부여해 Blueprint와 PART 5에서 추적 가능하게 함 |
| **출처·시점 명시** | 각 팩트에 출처(기사/IR/공식 홈페이지)와 시점(YYYY.MM)을 기록 |
| **검증 등급** | `✅ 확인됨`(공식·복수 출처) / `⚠️ 단일 출처`로 표기. **⚠️ 팩트의 구체 수치는 자소서에 그대로 쓰지 않고 정성 표현으로 순화** |
| **직무 연결 포인트** | 각 팩트가 지원 직무의 어떤 업무·과제와 연결되는지 1줄로 기술 |
| **활용 문항 지정** | 해당 팩트를 투입할 문항 번호를 미리 지정 |

### 3) Notion '자기소개서 경험 관리' DB 연동 (`notion-mcp-server`)
* Notion DB(ID: `2847d6f5-8fa5-80c4-98a9-e018fab7bcfc`) 및 세부 하위 페이지(예: `H-Mobility Class 자율주행 Track`, `스텔스 차선 HUD 시스템`, `ROS2`, `CAN/Ethernet 통신`, `오픈소스 SW대회`, `자격증` 등)를 `API-post-search` 또는 `API-retrieve-page-markdown`으로 탐색하여 지원자의 실제 프로젝트명, 사용 기술 스택, 에러 해결 사례, 정량 수치를 인출합니다.

## 3. STAGE 2 세부 수행 지침 (자소서 집필 & 정밀 검증 & 역동기화)

사용자가 작성을 승인하면 다음 4개 파트를 완성하여 출력합니다.

### 1) PART 5. 문항별 실전 합격 자기소개서 완성본 (`writer-job`)
* **비즈니스 6대 원칙 (`내·형·표·구·간·명`) 엄수**:
  - **내(내용)**: 질문 요지 및 나의 직무 역량 집중 (회사 단순 칭찬 배제)
  - **형(형식)**: 주어-목적어-서술어 직관적 문장 구조
  - **표(표현)**: 비즈니스 문어체 (감성적 구어체 엄금)
  - **구(구체성)**: 기간, 횟수, 수치(%), 건수 등 정량 데이터 필수 배치
  - **간(간결성)**: 1문장 30~40자 내외의 단문(워드 기준 한 줄) 원칙
  - **명(명확성)**: 두괄식 결론 앵커링

* ★ **STEP 1 리서치 연계 집필 원칙 (Research Integration Rules)**:
  1. **의무 반영**: 사용자가 제시한 **모든 문항**에 Blueprint에서 배정한 리서치 팩트를 반영합니다. 원칙적으로 문항당 **1~2개**를 투입하며, 성격상 기업 정보가 어색한 문항(예: 성장과정, 취약점)은 배정 시 '선택'으로 표시하고 마무리 1문장에서만 연결합니다.
  2. **연결 공식 — `[리서치 팩트] → [그 안의 실무 과제] → [나의 경험·역량] → [기여 방식]`**: 팩트는 반드시 지원자의 경험과 이어지는 '다리'로 사용합니다. 팩트만 나열하고 끝나는 문장은 금지합니다.
     - ❌ *Bad*: "귀사는 2026년 전동화 PE 신공장 양산을 시작하며 업계를 선도하고 있습니다."
     - ⭕ *Good*: "2026년 PE 신공장 양산 착수로 초기 불량 안정화가 핵심 과제가 될 것입니다. CAN 로그 300건을 분석해 결함 원인을 좁힌 경험으로 양산 초기 품질 확보에 기여하겠습니다."
  3. **분량 상한**: 기업·산업 정보 서술은 문항 전체 분량의 **15~25% 이내**로 제한하고, 나머지는 지원자의 행동(Action)과 성과(Result)에 집중합니다.
  4. **찬양 금지**: "업계 1위", "세계 최고", "선도하는" 등 평가 형용사로 팩트를 포장하지 않고, 사실과 과제만 담백하게 서술합니다.
  5. **정확성**: `⚠️ 단일 출처` 팩트의 구체 수치·날짜는 직접 인용하지 않고 정성 표현으로 순화합니다. 리서치에서 확인되지 않은 수치를 새로 만들지 않습니다.
  6. **중복 방지**: 같은 팩트를 여러 문항에 반복 사용하지 않습니다. (불가피하면 문항마다 다른 관점으로 사용)

* **문항 유형별 리서치 팩트 배치 가이드**:
  | 문항 유형 | 우선 투입 팩트 | 배치 위치 |
  | :--- | :--- | :--- |
  | 지원동기 / 입사 후 포부 | 신사업·중장기 전략, CEO 화두, 산업 위기/기회 | 도입부(기업이 처한 과제 제시) + 마무리(기여 선언) |
  | 직무 역량 / 전문성 | 기술 로드맵, 실무 페인포인트, 신제품·양산 이슈 | 3K(입사 후 기여) 파트 |
  | 도전 / 문제해결 | 업계 공통 난제, 품질·리콜 이슈 | Insight(향후 기여점) 파트 |
  | 협업 / 갈등 / 윤리 | 조직문화·핵심가치, 협업 구조 변화 | 마무리 매듭 |
  | 성장과정 / 가치관 | 인재상·핵심가치 원문 | 3단계(확장/실무) 연결 문장 |
  | 사회 / 산업 이슈 | 정책·규제, 최신 뉴스, 경쟁사 동향 | 이슈 요약 + 다각도 분석 전반 (예외적으로 팩트 비중 확대 허용) |
  | 가장 취약한 점 | (선택) 직무 리스크 관련 팩트 | V 단계 마지막 1문장 |

* **문항 유형별 특화 프레임워크**:
  - *지원동기/포부*: 옴스잡스 3단계 (산업 주관적 가치 $\rightarrow$ 기업 강점 본인만의 해석 $\rightarrow$ 위기 돌파 기여 선언 / *"배우겠다"* 엄금)
  - *직무 역량*: 3단계 답변법 & KKK + 1차/2차 역량 이층 구조 + 집요함(정량적/정성적) + 작은 T자형 인재
  - *성장과정*: 상향식 3단계 (일상 계기 $\rightarrow$ 학문 $\rightarrow$ 실무 리스크) + 생각(Thought)의 과정 중심
  - *도전/문제해결*: 3C4P & Insight 5단계 (Action 50% 이상 집중)
  - *협업/갈등/윤리*: 의견 상충 $\rightarrow$ 맞춤형 조율 $\rightarrow$ 자기 성찰/책임 자각 $\rightarrow$ 원칙 준수
  - *사회이슈*: 이슈 요약(200자) $\rightarrow$ 다각도 분석(300자) $\rightarrow$ 친기업 관점 제언(300자)
  - ★ **가장 취약한 점 / 단점 및 약점 극복 (R-C-S-V 특화 프로토콜)**:
    - **R (Recognition & Definition, 20%)**: 클리셰(완벽주의, 거절 못함, 일 욕심) 및 직무 결격 사유(덤벙댐, 대인기피, 안전불감증) 철저 배제. 실제 업무 맥락에서 발생할 수 있는 인지적/프로세스적 취약점을 솔직하고 정밀하게 정의.
    - **C (Cause Analysis, 10~15%)**: 취약점 발생의 심리적/업무적 메커니즘을 객관적으로 분석하는 메타인지 서술.
    - **S (Systematic Safeguard, 45~50% - 핵심)**: 단순 "노력하겠다"는 피동적 다짐 배제. **오류를 원천 차단하는 구체적 도구와 행동 루틴(타임박싱, 3단계 셀프 QA 체크리스트, 우선순위 매트릭스, 더블체크 프로토콜)**을 시스템화하여 제시.
    - **V (Validation by Real Case, 20~25%)**: 보완 시스템을 실제 프로젝트에 적용하여 이전의 취약점을 선제 차단하고 성공적인 결과(일정/품질 준수)를 거둔 실증 사례 제시 및 입사 후 리스크 제로화 매듭.
* **글자 수 엄수**: 지정 글자 수의 **85% ~ 95%** 충족.
